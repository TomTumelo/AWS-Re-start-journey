## ☁️ AWS Cloud Quest: Cloud Practitioner

📁 [`/aws-cloud-practitioner/`](./aws-cloud-practitioner/)

AWS Cloud Quest is a role-playing game that teaches real AWS skills through hands-on cloud challenges. Completing the **Cloud Practitioner** path demonstrates foundational knowledge of AWS services, cloud concepts, and global infrastructure.

**Skills covered:** EC2, S3, RDS, IAM, VPC, Lambda, CloudWatch, pricing models, shared responsibility model.

---

## 🔒 AWS SimuLearn: Core Security Concepts

📁 [`/aws-security/`](./aws-security/)

A simulation-based learning experience focused on cloud security fundamentals within AWS. Covers how to protect AWS environments through identity management, access controls, and threat mitigation.

**Skills covered:** IAM policies, MFA, encryption at rest & in transit, AWS Shield, GuardDuty, Security Groups, NACLs.

---

## 🌐 AWS SimuLearn: Networking Concepts

📁 [`/aws-networking/`](./aws-networking/)

Hands-on simulation covering how networks are built and managed in the AWS cloud. Focuses on architecting reliable, scalable network infrastructure.

**Skills covered:** VPC design, subnets, route tables, Internet Gateways, NAT Gateways, VPN, Direct Connect, Elastic Load Balancing.

---

## 🗄️ Databases in Practice

📁 [`/databases-in-practice/`](./databases-in-practice/)

A practical introduction to database concepts and AWS managed database services. Covers both relational and non-relational databases and when to use each.

**Skills covered:** SQL fundamentals, Amazon RDS, DynamoDB, Aurora, database backup & recovery, read replicas, high availability.

---

## 🤖 Exploring Artificial Intelligence

📁 [`/exploring-ai/`](./exploring-ai/)

An introductory course exploring the landscape of artificial intelligence — what it is, how it works, and how AWS makes AI accessible to builders of all skill levels.

**Skills covered:** AI vs ML vs Deep Learning, AWS AI services (Rekognition, Comprehend, Polly, Lex, Translate), responsible AI principles.

---

## 🧠 Fundamentals of Machine Learning & AI

📁 [`/ml-and-ai-fundamentals/`](./ml-and-ai-fundamentals/)

A deeper dive into the mechanics of machine learning — from data preparation to model training and evaluation — using AWS tools and frameworks.

**Skills covered:** Supervised vs unsupervised learning, training/validation/test splits, Amazon SageMaker, feature engineering, model evaluation metrics, bias & fairness in ML.
