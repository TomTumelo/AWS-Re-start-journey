## 📚 What I Learned

### The AI Landscape

```
Artificial Intelligence (AI)
└── Machine Learning (ML)
    └── Deep Learning (DL)
        └── Generative AI (GenAI)
            └── Large Language Models (LLMs)
```

- **AI**: Systems that simulate human intelligence
- **ML**: Systems that learn from data without explicit programming
- **Deep Learning**: ML using neural networks with many layers
- **Generative AI**: Models that create new content (text, images, code, audio)

### Types of AI Problems
| Type | What it does | Example |
|---|---|---|
| **Classification** | Assigns a category | Is this email spam? |
| **Regression** | Predicts a number | What will this house sell for? |
| **Clustering** | Groups similar items | Segment customers by behavior |
| **Recommendation** | Suggests relevant items | "You might also like..." |
| **Computer Vision** | Understands images/video | Detect faces, read text in images |
| **NLP** | Understands language | Sentiment analysis, translation |

### Responsible AI Principles

AWS and the broader AI community emphasize these pillars:

1. **Fairness** — Models shouldn't discriminate based on protected characteristics
2. **Explainability** — Can we understand *why* the model made a decision?
3. **Privacy** — Protect personal data used in training and inference
4. **Robustness** — Models should be reliable and resistant to adversarial inputs
5. **Transparency** — Be honest about where and how AI is used
6. **Governance** — Humans should remain in control of high-stakes decisions

## 💡 Key Takeaways

1. **You don't need to build models to use AI** — AWS pre-built AI services cover 80% of common use cases.
2. **AI is a tool, not magic** — it works best on well-defined, data-rich problems.
3. **Garbage in, garbage out** — model quality is entirely dependent on training data quality.
4. **Responsible AI isn't optional** — bias in models has real consequences for real people.
5. **Start with the problem, not the technology** — don't reach for AI when a simple rule-based system works fine.
