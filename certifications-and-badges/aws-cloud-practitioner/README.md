## What is AWS Cloud Quest?

AWS Cloud Quest is an **immersive, role-playing game** built by AWS to teach cloud skills through real, hands-on labs. Unlike traditional courses, you solve real-world city challenges using actual AWS services — no sandbox, real cloud.

The **Cloud Practitioner** role is the entry point: you help a virtual city by deploying web apps, setting up storage, and keeping services running — all while learning core AWS concepts.

## 📚 What I Learned

### Cloud Concepts
- The 6 advantages of cloud computing (trade CapEx for OpEx, stop guessing capacity, etc.)
- Cloud deployment models: Public, Private, Hybrid
- AWS Global Infrastructure: Regions, Availability Zones, Edge Locations

### Core AWS Services
| Category | Services |
|---|---|
| Compute | EC2, Lambda, Elastic Beanstalk |
| Storage | S3, EBS, EFS, Glacier |
| Database | RDS, DynamoDB |
| Networking | VPC, Route 53, CloudFront |
| Security | IAM, Shield, WAF |
| Monitoring | CloudWatch, CloudTrail |

### Pricing & Support
- AWS Free Tier
- Pay-as-you-go, Reserved, Spot pricing models
- AWS Pricing Calculator
- Support plans (Basic → Enterprise)

### Shared Responsibility Model
- **AWS** is responsible for security **of** the cloud (hardware, facilities, infrastructure)
- **Customer** is responsible for security **in** the cloud (data, OS configs, IAM)

## 💡 Key Takeaways

1. **Think in services, not servers** — AWS abstracts the complexity. Focus on what the service does, not the underlying hardware.
2. **IAM is everything** — Before touching any service, understand who has access to what.
3. **Cost optimization is a skill** — The right pricing model can drastically cut cloud bills.
4. **High availability ≠ expensive** — Multi-AZ setups are often more affordable than you'd think.
