## 🏗️ E-Commerce Platform Architecture on AWS

📁 [`/E-Commerce Platform Architecture on AWS/`](./E-Commerce%20Platform%20Architecture%20on%20AWS/)

Designed a production-grade **3-tier cloud architecture** for a scalable e-commerce platform on AWS. The architecture covers the web tier, application tier, and database tier with high availability across multiple Availability Zones.
