# Lab 02 - Build Your DB Server and Interact With Your DB Using an App

## Overview
This lab covers launching an Amazon RDS MySQL instance with high availability,
configuring security groups, and connecting a web application to the database.

## Objectives
- Launch an Amazon RDS DB instance with Multi-AZ
- Configure security groups to allow web server access
- Connect a web application to the RDS database

## Duration
Approximately 45 minutes
