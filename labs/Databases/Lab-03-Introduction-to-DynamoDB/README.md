**Services:** DynamoDB
**Status:** ✅ Complete

## 🎯 Objective

Learn the fundamentals of Amazon DynamoDB by creating a music library table, inserting records, querying data, updating items, and deleting the table.

---

## ✅ Tasks Completed

* Created `Music` table
* Added multiple music items
* Updated existing record
* Queried by partition and sort key
* Scanned using filters
* Deleted the table

---

## 🧠 Key Concepts Learned

* NoSQL database design
* Partition key & sort key
* Query vs Scan
* Flexible schema model
* Item updates
