# Lab 233 – Working with the Linux File System

## Overview
This lab covers core Linux file system operations including creating folder structures, copying, moving, and deleting files and directories on an Amazon Linux EC2 instance.

## Objectives
- Create a folder structure
- Create files
- Copy and move files and directories
- Delete files and directories

## Duration
Approximately 30 minutes
