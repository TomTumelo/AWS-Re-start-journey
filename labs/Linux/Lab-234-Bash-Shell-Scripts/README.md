# Lab 234 – Bash Shell Scripts

## Overview
This lab covers creating a Bash shell script that automates the backup of a folder into a compressed archive on an Amazon Linux EC2 instance.

## Objectives
- Write a Bash shell script
- Use variables and the `date` command
- Create a compressed tar archive
- Make a script executable

## Duration
Approximately 25 minutes
